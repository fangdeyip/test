# 课堂练习3 —— 数字逻辑可视化演示

一个**纯静态、离线可用**的数字逻辑演示工具：围绕「布尔表达式 / 真值表 / 波形图 / 卡诺图 / 逻辑电路图」五种表示形式的对应关系进行可视化呈现，输入或切换任意一个视图，其余四个视图会**实时联动更新**。

## 打开方式

双击 `index.html` 即可在浏览器中打开，无需任何服务器、无需联网。

## 目录结构

```
practice-03
├── .gitignore        # 忽略编辑器缓存与系统垃圾
├── index.html        # 演示页入口
├── intro.html        # 练习小结页（被 index.html 链接）
├── style.css         # 纸质教材风样式
├── logic.js          # 表达式解析与逻辑运算
├── render.js         # 五种视图的渲染
├── README.md
```

## 功能特性

- **支持 2 / 3 / 4 变量**：根据表达式中出现的字母自动识别变量数
- **运算符**：`&` `*`（与）、`|` `+`（或）、`^`（异或）、`!` `~` `'`（非）、括号
- **预设函数**：内置与、或、非、异或、同或、半加器、全加器 7 个示例，一键加载
- **五种视图联动**：任一变量变化，所有视图同步刷新
- **卡诺图圈选化简**：自动按 1、2、4、8 大小搜索素蕴含，鼠标悬停高亮对应单元格
- **波形图**：时间轴横轴，自动随真值表行序展开

## 使用说明

1. 在输入框内输入布尔表达式（如 `AB + A''C`）
2. 或点击下方预设按钮加载示例
3. 改变任意变量值（或点击真值表行），观察五个视图的同步变化
4. 卡诺图上鼠标悬停素蕴含圈时，对应单元格会高亮
