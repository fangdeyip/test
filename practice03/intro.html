一、练习目标

本次练习要求开发一个**纯静态、离线可用**的数字逻辑可视化演示页面，围绕以下五种表示形式进行可视化呈现和交互：

  • 布尔表达式（Boolean Expression）
  • 真值表（Truth Table）
  • 波形图（Waveform / Timing Diagram）
  • 卡诺图（Karnaugh Map）
  • 逻辑电路图（Logic Circuit Diagram）

核心约束：

  • 纯原生 HTML + CSS + JavaScript，不依赖任何 CDN、外网资源或在线 API
  • 支持 2 / 3 / 4 变量自动识别
  • 五种视图实时联动，任一变量变化其余四视图同步刷新
  • 双击即可打开，断网也能正常演示
  • 不提交任何图片文件到 git 仓库

三、数字逻辑基础概念

1. 基本逻辑运算

运算符号含义口诀
与（AND） ·  / &全1出1有0出0
或（OR）+有1出1全0出0
非（NOT）' / ! / ~取反0→1, 1→0
异或（XOR）⊕不同出1相同出0

2. 布尔代数化简

化简的目标是用最少的门实现同一逻辑功能，主要方法：

  • 代数法：应用吸收律 A+AB=A、A·(A+B)=A 等
  • 卡诺图法：图上圈选相邻"1"格，圈越大项越少
  • Quine-McCluskey 法：系统化算法，适合计算机实现
素蕴含（Prime Implicant）：不能再与其他项合并的蕴含项。化简时优先选择本质素蕴含（Essential PI），即被唯一某个小项覆盖的素蕴含。

3. 五种表示形式的对应关系

同一逻辑函数可以用五种方式等价表示，它们之间存在一一对应的映射关系：

  • 布尔表达式 ↔ 真值表（代入变量值直接计算）
  • 真值表 ↔ 卡诺图（将输出填入 Gray 码排列的格子）
  • 卡诺图圈选化简 ↔ 化简后的布尔表达式
  • 布尔表达式 ↔ 逻辑电路图（AND-OR-NOT 门实现）
  • 真值表 ↔ 波形图（以时间轴展开各变量的高低电平）

四、演示页开发过程

步骤 1：创建目录结构

步骤 2：编写 .gitignore
# node 依赖（如果后续用到） node_modules/ # 编辑器缓存 .vscode/ .idea/ *.swp # 系统垃圾 .DS_Store Thumbs.db # 临时文件 *.tmp *.log *.log*

步骤 3：核心模块 — logic.js（表达式解析引擎）

实现一个支持以下语法的递归下降解析器：

运算符含义优先级
()括号最高
! ~ '非（NOT）次高
& *与（AND）中等
| +或（OR）较低
^异或（XOR）最低

自动识别表达式中的变量（A-Z），支持 1~4 个变量。内置 Quine-McCluskey 算法进行化简，输出素蕴含列表。

步骤 4：核心模块 — render.js（五视图渲染）

  • 真值表：DOM 表格渲染，点击行高亮，其他视图同步联动
  • 波形图：Canvas 绘制时序图，Gray 码时间轴，鼠标悬停显示步数
  • 卡诺图：Gray 码布局，支持鼠标悬停高亮相邻格，素蕴含悬停高亮整组
  • 电路图：SVG 绘制逻辑门（AND / OR / XOR / NOT / NAND），自动布局
  • 表达式面板：规范化显示原表达式与化简结果

步骤 5：样式设计（style.css）

采用纸质教材风格，配色参考：

元素颜色说明
纸张底色#f5f0e8（米黄）模拟旧书纸张
墨水色#1a1a1a（近黑）正文、边框
批注蓝#1a5276（淡蓝）链接、面板标题
批注红#c0392b（淡红）当前行高亮、强调
批注绿#196f3d（墨绿）化简结果、素蕴含
荧光笔黄#fff3b0悬停/选中背景

字体：Georgia / Times New Roman / Noto Serif CJK SC（衬线），Courier New / 等线（等宽）。
避免：紫色渐变、玻璃拟态、过度圆角、任何 AI 感的现代 UI 元素。
